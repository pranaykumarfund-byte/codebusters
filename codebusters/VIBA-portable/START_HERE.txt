VIBA — ABHA redefined....!

The desktop navigation stays visible while the main content scrolls. On smaller screens it opens as a slide-in menu. The app uses the dark navy and teal theme shown in the supplied reference.

Start on Windows
1. Install Node.js 20 or newer if needed.
2. Extract this ZIP to a normal folder.
3. Double-click START_VIBA.bat. It selects an available local port, starts the mock API, waits for a response, then opens the browser.
4. Keep the VIBA server window open while using the app.

Double-click RUN_TESTS.bat to run 36 automated tests.

The dashboard includes random fictional vitals and an offline scripted chat. Neither uses real data or a healthcare service. Chat replies may be inaccurate. Do not enter real personal or health information.
